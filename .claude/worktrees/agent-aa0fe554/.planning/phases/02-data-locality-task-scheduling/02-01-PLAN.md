<objective>
Add data-locality-aware GPU selection to the task creation and reservation flow.

Purpose: Today gpu_pipeline_executor makes reservations on its own fixed _memory_space. This plan changes it so each task carries a preferred_device_id computed from data locality, and the reservation uses cucascade's `any_memory_space_in_tier_with_preference` strategy to try the preferred GPU first, fall through to other GPUs, and only block if no GPU can reserve. The reservation attempt IS the routing mechanism (per user decision). The pull model (GPU sends task_request, management_eventloop responds) is preserved.

Output: task_creator computes preferred_device_id per task, gpu_pipeline_executor uses it in reservation strategy, tasks execute where data lives.
</objective>

     ```cpp
     // Compute preferred GPU based on data locality
     std::optional<int> preferred_device_id;
     if (input_data && !input_data->get_data_batches().empty()) {
       std::unordered_map<int, size_t> gpu_bytes;
       std::unordered_map<int, size_t> host_bytes;
       for (const auto& batch : input_data->get_data_batches()) {
         auto* space = batch->get_memory_space();
         if (!space || !batch->get_data()) continue;
         auto size = batch->get_data()->get_size_in_bytes();
         if (space->get_tier() == cucascade::memory::Tier::GPU) {
           gpu_bytes[space->get_device_id()] += size;
         } else if (space->get_tier() == cucascade::memory::Tier::HOST) {
           host_bytes[space->get_device_id()] += size;
         }
       }
       if (!gpu_bytes.empty()) {
         // SCHED-01: Route to GPU with most data by bytes
         preferred_device_id = std::max_element(
           gpu_bytes.begin(), gpu_bytes.end(),
           [](const auto& a, const auto& b) { return a.second < b.second; }
         )->first;
       } else if (!host_bytes.empty() && !_numa_to_gpu.empty()) {
         // SCHED-02: No GPU data, route to GPU on same NUMA as host data
         auto top_host = std::max_element(
           host_bytes.begin(), host_bytes.end(),
           [](const auto& a, const auto& b) { return a.second < b.second; }
         )->first;
         auto it = _numa_to_gpu.find(top_host);
         if (it != _numa_to_gpu.end()) {
           preferred_device_id = it->second;
         }
       }
     }
     if (preferred_device_id.has_value()) {
       local_state->set_preferred_device_id(preferred_device_id.value());
     }
     ```
   - Add necessary includes: `<cucascade/memory/common.hpp>` or wherever Tier is defined, `<algorithm>`, `<unordered_map>`

**Critical design: Keep the pull model. The reservation attempt IS the routing mechanism.**

The management_eventloop is NOT changed. It keeps the current pull model:
- GPU executor sends task_request ("I'm ready")
- management_eventloop pops task from _task_queue
- management_eventloop dispatches to the GPU that requested

The routing happens at reservation time inside gpu_pipeline_executor::manager_loop().

   **Current reservation flow** (around line 98):

   or equivalent call through `_mem_res_mgr`.

   **New reservation flow** (implements SCHED-03):
   ```cpp
   // Read task's preferred_device_id
   std::optional<size_t> preferred;
   if (auto* gpu_task = dynamic_cast<gpu_pipeline_task*>(task.get())) {
     auto pref = gpu_task->get_preferred_device_id();
     if (pref.has_value()) {
       preferred = static_cast<size_t>(pref.value());
     }
   }

   // SCHED-03: Reservation tries preferred GPU first, then other GPUs, blocks if none can reserve
   // cucascade's any_memory_space_in_tier_with_preference naturally provides this behavior:
   //   - It tries the preferred memory space first
   //   - If that fails, it falls through to other memory spaces in the same tier
   //   - If all fail, it blocks (waits) until one becomes available
   //   - The preference ordering means it will unblock on preferred GPU first if multiple free simultaneously
   auto reservation = _mem_res_mgr->request_reservation(
     cucascade::memory::any_memory_space_in_tier_with_preference{
       cucascade::memory::Tier::GPU, preferred},
     bytes_needed);
   ```
